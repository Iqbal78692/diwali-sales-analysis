# diwali-sales-analysis
Python project to analyze Diwali sales data using Pandas, Matplotlib, and Seaborn. Includes data cleaning, exploratory data analysis, and insights on customer purchasing behavior.
# 🪔 Diwali Sales Analysis using Python  

This project analyzes **Diwali Sales Data** to understand customer purchasing behavior and identify factors driving sales during the festive season.  
The insights can help businesses improve **marketing strategies** and boost **sales performance**.  

---

## 📊 Objectives  
- Clean and preprocess the raw dataset  
- Perform exploratory data analysis (EDA)  
- Study customer demographics (gender, age, marital status, occupation, state)  
- Identify top-selling product categories  
- Generate business insights and recommendations  

---

## 📂 Dataset  
The dataset contains Diwali sales transactions with the following details:  
- **Customer details**: Gender, Age Group, Marital Status, State, Occupation  
- **Product details**: Product ID, Product Category  
- **Sales details**: Orders, Amount  

*(Dataset file is included in the repository)*  

---

## 🛠️ Tools & Libraries  
- Python  
- Pandas → data cleaning & manipulation  
- Matplotlib & Seaborn → data visualization  
- Jupyter Notebook → coding & analysis  

---

## 🔎 Analysis & Key Insights  
1. **Customer Demographics**  
   - Women purchased more compared to men  
   - Age group **26–35 years** contributed the highest sales  

2. **Marital Status**  
   - Married women were the most profitable customers  

3. **Occupation**  
   - IT, Healthcare, and Aviation professionals showed higher purchasing power  

4. **State-wise Sales**  
   - Top 3 states: **Uttar Pradesh, Maharashtra, Karnataka**  

5. **Product Categories**  
   - Most sold: **Clothing & Apparel, Food, Electronics**  

---

## 📌 Business Recommendations  
- Focus on **married women aged 26–35 years**  
- Target marketing campaigns in **Uttar Pradesh, Maharashtra, and Karnataka**  
- Promote **clothing, food, and electronics** categories during festive offers
